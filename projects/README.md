# AI / Machine Learning Portfolio Projects

Five practical AI/ML applications built with Python, Streamlit, scikit-learn, Hugging Face, and local LLM tooling.

| Project | Focus | Stack |
|---|---|---|
| [RAG Document Assistant](./rag-document-assistant/) | PDF retrieval and grounded Q&A | TF-IDF, Ollama, Streamlit |
| [Resume & Job Match Analyzer](./resume-job-match-ai/) | Resume/JD similarity and skill coverage | NLP, scikit-learn |
| [Customer Churn Prediction](./customer-churn-prediction/) | Classification, evaluation, scoring | scikit-learn, Pandas |
| [Vision Transformer Classifier](./image-classification-vit/) | Pretrained image classification | ViT, Transformers, PyTorch |
| [Financial News Sentiment](./financial-news-sentiment/) | Financial NLP sentiment | FinBERT, Transformers |

## Run any project

Open its folder, create a virtual environment, install its `requirements.txt`, and run:

```bash
streamlit run app.py
```

Each project has its own README with setup instructions, model details, and limitations.

## Portfolio note

These are educational portfolio applications. Review the code, test with suitable datasets, record reproducible results, and understand the models before presenting them in interviews. Do not treat demo outputs as production-grade or high-impact decisions.
